# TaskManagerAPI 🚀

REST API для управления списком задач (To-Do List), разработанный на ASP.NET Core. 
Проект создан для демонстрации навыков backend-разработки и работой с базой данных.

## 🛠️ Стек технологий
-  **Язык:** C# / .NET 8
-   **Фреймворк:** ASP.NET Core Web API
-   **База данных:** MS SQL Server, Entity Framework Core
-   **Архитектура:** Controller-Service-Repository (через DI)
-   **Документация:** Swagger
-   **Логирование:** Кастомный FileLogger (через события и IDisposable)

## ⚙️ Что умеет API
-   **CRUD операции:** Создание, чтение, обновление и удаление задач.
-   **Фильтрация:** Поиск задач по статусу выполнения (`IsCompleted`).
-   **Поиск:** Поиск задачи по названию (без учета регистра).
-   **Логирование:** При создании задачи событие передается в логгер, который пишет данные в файл `log.txt` без блокировки основного потока.

### 📌 Основные эндпоинты
| Метод | Маршрут | Описание |
|-------|---------|----------|
| `GET` | `/Tasks` | Получить список всех задач |
| `GET` | `/Tasks/{id}` | Получить задачу по ID |
| `POST` | `/Tasks` | Создать новую задачу |
| `PUT` | `/Tasks/{id}` | Обновить существующую задачу |
| `DELETE` | `/Tasks/{id}` | Удалить задачу |
| `GET` | `/Tasks/searchOfTitle/{title}` | Найти задачу по названию |
| `GET` | `/Tasks/searchOfIsCompleted/{bool}` | Фильтр по статусу |
